AI Engine Settings

Google Gemini & Intelligence Mode

Festiva AI uses the built-in Festiva Intelligent Heuristic Engine by default. When a secured server-side Gemini backend is configured, new plans can use Google Gemini Generative AI.

With Gemini enabled, selected event details (such as date, location, budget, dietary notes, and cultural preferences) are sent to Google to generate a plan. The guest directory is not included. Avoid entering sensitive personal information.

Secure Gemini configuration

For Gemini mode, set GEMINI_API_KEY as an environment variable on your backend host. Never paste a secret into this page or commit it to GitHub. The browser does not store an API key.

When no secured backend is configured, all planning features continue to work using the built-in heuristic engine. If you use the hosted AI backend, relevant event-planning fields are sent to Google Gemini to generate the plan.
